...

You can use only 2 images if you want. If you use 3, all 3 will show in the slider.

IMPORTANT:
1. Replace the sample product images with your own files using the exact filenames.
2. Product names/prices can be edited in the products array inside index.html.
3. The email endpoint is currently set to the email supplied by the owner.
4. FormSubmit may require an activation/confirmation email the first time.
5. This is a front-end starter store. It does not provide a secure admin database or payment gateway.
